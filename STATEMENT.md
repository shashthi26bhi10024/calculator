## 1. Problem Statement

Basic calculators often provide only simple arithmetic operations, while users may need additional mathematical functions such as percentage, powers, square roots, trigonometric calculations, logarithms, calculation history, and memory operations.

The objective of this project is to develop a modular calculator application in Python that combines these commonly required mathematical operations into one organized system. The project also demonstrates programming concepts such as functions, modules, conditional logic, error handling, and structured software design.

## 2. Scope of the Project

The project covers the development of a Python-based calculator with five major functional modules:

- Basic arithmetic calculations
- Advanced mathematical calculations
- Calculation history
- Memory operations


## 3. Target Users

The intended users are:

- Students
- Beginners learning programming
- Users who need a simple calculator for everyday mathematical operations
- Users who want basic scientific calculations in the same application

## 4. High-Level Features

### Basic Calculator
Addition, subtraction, multiplication, and division.

### Advanced Calculator
Percentage, square, square root, and power operations.


### Calculation History
Stores calculations during the current session and allows the user to view or clear them.

### Memory Functions
Provides M+, M−, MR, and MC operations.

## 5. Project Objectives

1. Building a functional calculator using Python.
2. Applying modular programming principles.
3. Demonstrate the use of mathematical functions and the Python `math` module.
4. Implementing input validation and error handling.
5. Provide a clear flow for performing calculations.
6. Create a maintainable project structure suitable for version control.

## 6. Expected Outcome

The final system will provide a single calculator application in which users can perform basic, advanced, and scientific calculations while also using history and memory features.
